# 🤖 Техническое задание (ТЗ) на разработку бота для загрузки сайтов в парсер

## 📌 Суть задачи

Разработать **Telegram-бота** (или альтернативное решение), который позволит пользователю **загружать список сайтов** для парсинга в формате **Excel**.

🔹 Бот должен **принимать файл**, сохранять его, **выводить содержимое** и **сохранять данные в локальную БД (SQLite)**.

🔹 Дополнительно: **производить парсинг** по загруженным данным и выводить **среднюю цену** товаров.

---

## 🎯 Функциональные требования

### 1️⃣ Интерфейс

- Бот должен содержать **кнопку**: `📂 Загрузить файл`
    
- После нажатия **пользователь прикрепляет Excel-файл** с нужными данными.
    

### 2️⃣ Формат загружаемого файла (Excel, .xlsx)

Файл должен содержать таблицу с колонками:

|title|url|xpath|
|---|---|---|
|Название товара|Ссылка на сайт|XPath к цене|

Пример данных:

|title|url|xpath|
|---|---|---|
|Зюзюблик|[https://example.com](https://example.com)|//*[@id='price']|

### 3️⃣ Обработка загруженного файла

1. Бот **сохраняет файл**.
    
2. **Открывает файл** с помощью `pandas`.
    
3. **Выводит содержимое** пользователю.
    
4. **Сохраняет данные** в локальную **SQLite БД**.
    

### 4️⃣ База данных (SQLite)

- Таблица `sites`:
    

```sql
CREATE TABLE sites (
    id INTEGER PRIMARY KEY,
    title TEXT,
    url TEXT,
    xpath TEXT
);
```

- Данные из загруженного файла **добавляются в БД**.
    

### 5️⃣ Задача со звёздочкой ⭐

1. **Спарсить цены** по загруженным данным.
    
2. **Очистить значения цен** (убрать пробелы, валюту и прочие символы).
    
3. **Рассчитать среднюю цену по каждому сайту** и вывести результат пользователю.
    

---

## ⚙️ Технологический стек

- **Язык**: Python 3.x 🐍
    
- **Фреймворк**: Aiogram (для Telegram-бота) 📟
    
- **Парсинг**: `requests`, `lxml`, `BeautifulSoup` 🌐
    
- **Работа с файлами**: `pandas` 📊
    
- **База данных**: SQLite 🛢
    
- **Контейнеризация**: Docker 🐳 _(опционально)_

## 🚀 Инструкция по развёртыванию

1. Установить зависимости:
    

```sh
pip install -r requirements.txt
```

2. Запустить бота:
    

```sh
python bot.py
```

3. Взаимодействовать с ботом через Telegram.
