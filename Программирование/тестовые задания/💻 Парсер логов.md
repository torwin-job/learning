# 🧪 Тестовое задание: CLI-приложение для анализа логов Django

## 📌 Что нужно сделать?

Разработать CLI-приложение на Python, которое **анализирует логи Django-приложения** и **формирует отчёты** по заданному формату. Отчёты выводятся в **консоль**.

---

## 🧰 Интерфейс приложения

Приложение запускается из терминала следующим образом:

```bash
python3 main.py logs/app1.log logs/app2.log logs/app3.log --report handlers
```

- Можно передавать **один или несколько путей к логам**
    
- Через аргумент `--report` указывается название отчёта, который необходимо сформировать
    -

---

## 📄 Формирование отчёта на основе нескольких файлов

Каждый лог-файл обрабатывается **отдельно**, после чего **данные объединяются** в итоговый отчет.

Пример:

- `app1.log`: 3 млн запросов
    
- `app2.log`: 2 млн запросов  
    📊 Итого в отчёте: 5 млн запросов
    

---

## 📑 Отчёты

### ✅ Отчёт №1: `handlers`

**Название отчета:** `handlers`

### 📊 Алгоритм формирования отчёта:

- Фильтруются записи логов вида: `django.request`
    
- Для каждой ручки (handler) считаются **количества логов по уровням логирования**:
    
    - DEBUG
        
    - INFO
        
    - WARNING
        
    - ERROR
        
    - CRITICAL
        
- Данные группируются **по ручкам**
    
- Итоговая таблица **сортируется по алфавиту**
    
- Последняя строка — **сумма** по каждому уровню
    
- Также выводится **общее количество запросов**
    

### 🔍 Пример вызова:

```bash
python3 main.py logs/app1.log logs/app2.log --report handlers
```

## ✅ Функциональные требования

### Основные:

- ✅ Можно сформировать отчёт `handlers` на основе **нескольких файлов**
    
- ✅ Пути к логам передаются как **позиционные аргументы**
    
- ✅ Название отчёта передаётся через аргумент `--report`
    

### Дополнительные:

- ⚠️ Проверяется, что указанные файлы **существуют**
    
- ⚠️ Проверяется, что имя отчета **валидное**

### Основные:

- ✅ Используется только **стандартная библиотека Python** (исключение: `pytest` для тестов)
    
- ✅ Обработка логов работает с файлами **размером в несколько гигабайт**
    
- ✅ Код покрыт **юнит- и интеграционными тестами** (`pytest`)
    
- ✅ Код содержит **аннотации типов**

    - Для добавления нового отчёта **не нужно переписывать основной код**
