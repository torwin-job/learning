# 🧪 Тестовое задание — Tron Info Microservice

## 📋 Описание

Разработать микросервис на FastAPI, который по заданному TRON-адресу предоставляет информацию:

- Баланс TRX
    
- Bandwidth
    
- Energy
    

Все запросы фиксируются в базе данных с указанием адреса кошелька. Также реализовать два типа тестов: интеграционный и модульный.

---

## 🔧 Требования к реализации

### 📌 Общие требования

- Язык: **Python 3**
    
- Фреймворк: **FastAPI**
    
- ORM: **SQLAlchemy**
    
- Работа с TRON: **tronpy**
    
- Тестирование: **Pytest**
    
- Использовать **аннотации типов (typing)**
    

---

## 🚀 Эндпоинты

### `POST /wallet-info/`

- **Описание**: Получение информации о TRON-адресе
    
- **Входные данные**: JSON с полем `address` — строка с TRON-адресом
    
- **Выходные данные**:
    
    ```json
    {
      "address": "TSwZ...7xKf",
      "balance": 123.456,
      "bandwidth": 5000,
      "energy": 300
    }
    ```
    
- **Дополнительно**: каждый запрос сохраняется в БД с логом о том, какой адрес запрашивался и когда
    

---

### `GET /wallet-info/`

- **Описание**: Получение последних записей из БД
    
- **Параметры запроса**:
    
    - `limit`: количество записей (по умолчанию 10)
        
    - `offset`: смещение (по умолчанию 0)
        
- **Выходные данные**: список последних запросов с информацией об адресах
    

---

## 🗃️ Структура таблицы в БД (предложение)

|Поле|Тип|Описание|
|---|---|---|
|id|Integer|Первичный ключ|
|address|String|TRON-адрес|
|created_at|DateTime|Время запроса|
