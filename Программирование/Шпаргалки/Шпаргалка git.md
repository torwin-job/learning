### **Шпаргалка по Git**  

#### **1. Настройка**  
```bash
git config --global user.name "Имя"          # Установить имя
git config --global user.email "email@example.com"  # Установить email
git config --global core.editor "nano"      # Установить редактор по умолчанию
```

#### **2. Создание и клонирование репозитория**  
```bash
git init                          # Инициализировать новый репозиторий
git clone <url-репозитория>       # Клонировать удалённый репозиторий
```

#### **3. Основные команды**  
```bash
git status                        # Показать состояние файлов
git add <файл>                    # Добавить файл в индекс
git add .                         # Добавить все изменённые файлы
git commit -m "Сообщение"         # Закоммитить изменения
git commit -am "Сообщение"        # Добавить и закоммитить все изменения
git log                           # Показать историю коммитов
git diff                          # Показать изменения (не добавленные в индекс)
git diff --staged                 # Показать изменения в индексе
```

#### **4. Ветки (branches)**  
```bash
git branch                        # Показать все ветки
git branch <имя-ветки>            # Создать новую ветку
git checkout <имя-ветки>          # Переключиться на ветку
git checkout -b <имя-ветки>       # Создать и переключиться на ветку
git merge <имя-ветки>             # Влить ветку в текущую
git branch -d <имя-ветки>         # Удалить ветку (локально)
```

#### **5. Работа с удалённым репозиторием**  
```bash
git remote -v                     # Показать удалённые репозитории
git remote add origin <url>       # Добавить удалённый репозиторий
git push -u origin <ветка>        # Отправить изменения в удалённый репозиторий
git pull                          # Получить изменения из удалённого репозитория
git fetch                         # Загрузить изменения без слияния
```

#### **6. Отмена изменений**  
```bash
git restore <файл>                # Отменить изменения в файле (не в индексе)
git restore --staged <файл>       # Убрать файл из индекса
git reset --hard HEAD             # Отменить все локальные изменения (осторожно!)
git revert <хэш-коммита>          # Отменить коммит, создав новый
```

#### **7. Дополнительно**  
```bash
git stash                         # Временно сохранить изменения
git stash pop                     # Вернуть сохранённые изменения
git tag <имя-тега>                # Создать тег
git show <хэш-коммита>            # Показать информацию о коммите
```
