# Конспект по паттерну "Адаптер" в Python


[[Подробный пример паттерна Адаптер в Python]]
## 1. Назначение паттерна Адаптер
Паттерн Адаптер (Adapter) — это структурный паттерн проектирования, который позволяет объектам с несовместимыми интерфейсами работать вместе. Он выступает как "прослойка" между двумя объектами, преобразуя интерфейс одного объекта в интерфейс, ожидаемый другим объектом.

## 2. Проблема, которую решает Адаптер
Когда:
- Нужно использовать существующий класс, но его интерфейс не соответствует требуемому
- Необходимо интегрировать компоненты с разными интерфейсами
- Хотите создать повторно используемый класс, который сотрудничает с классами, имеющими несовместимые интерфейсы

## 3. Структура паттерна
```
┌───────────────────┐       ┌───────────────────┐       ┌───────────────────┐
│    Клиентский     │       │     Адаптер       │       │   Адаптируемый    │
│     код (Client)  │──────>│    (Adapter)      │──────>│    (Adaptee)      │
└───────────────────┘       ├───────────────────┤       └───────────────────┘
                            │ + request(): void │
                            └───────────────────┘
```

## 4. Типы адаптеров
### 4.1. Адаптер класса (Class Adapter)
Использует множественное наследование для адаптации интерфейсов.

```python
class Target:
    def request(self) -> str:
        return "Целевой стандартный запрос"

class Adaptee:
    def specific_request(self) -> str:
        return ".eetpadA eht fo roivaheb laicepS"

class Adapter(Target, Adaptee):
    def request(self) -> str:
        return f"Адаптер: (ПЕРЕВОД) {self.specific_request()[::-1]}"

def client_code(target: Target) -> None:
    print(target.request())

if __name__ == "__main__":
    target = Target()
    client_code(target)
    
    adaptee = Adaptee()
    print(f"Адаптируемый: {adaptee.specific_request()}")
    
    adapter = Adapter()
    client_code(adapter)
```

### 4.2. Адаптер объекта (Object Adapter)
Использует композицию для адаптации интерфейсов (более гибкий подход).

```python
class Target:
    def request(self) -> str:
        return "Целевой стандартный запрос"

class Adaptee:
    def specific_request(self) -> str:
        return ".eetpadA eht fo roivaheb laicepS"

class Adapter(Target):
    def __init__(self, adaptee: Adaptee) -> None:
        self.adaptee = adaptee

    def request(self) -> str:
        return f"Адаптер: (ПЕРЕВОД) {self.adaptee.specific_request()[::-1]}"

def client_code(target: Target) -> None:
    print(target.request())

if __name__ == "__main__":
    target = Target()
    client_code(target)
    
    adaptee = Adaptee()
    print(f"Адаптируемый: {adaptee.specific_request()}")
    
    adapter = Adapter(adaptee)
    client_code(adapter)
```

## 5. Преимущества и недостатки
### Преимущества:
- Отделяет и скрывает от клиента преобразование интерфейсов
- Позволяет повторно использовать существующие классы
- Реализует принцип открытости/закрытости

### Недостатки:
- Усложняет код из-за введения дополнительных классов
- В случае адаптера класса невозможно адаптировать класс и его подклассы одновременно

## 6. Применение в Python
### 6.1. Пример с разными интерфейсами платежных систем
```python
class PayPal:
    def send_payment(self, amount: float) -> None:
        print(f"Отправка ${amount} через PayPal")

class StripePayment:
    def make_payment(self, amount: int, currency: str) -> None:
        print(f"Оплата {amount} {currency} через Stripe")

class StripeAdapter:
    def __init__(self, stripe: StripePayment) -> None:
        self.stripe = stripe

    def send_payment(self, amount: float) -> None:
        self.stripe.make_payment(int(amount * 100), "USD")

def process_payment(payment_system, amount):
    payment_system.send_payment(amount)

paypal = PayPal()
stripe = StripePayment()
stripe_adapter = StripeAdapter(stripe)

process_payment(paypal, 100.50)
process_payment(stripe_adapter, 100.50)
```

### 6.2. Адаптер для работы с разными типами данных
```python
class OldSystem:
    def get_data(self) -> list:
        return ["data1", "data2", "data3"]

class NewSystem:
    def process_data(self, data: dict) -> None:
        print(f"Обработка данных: {data}")

class DataAdapter:
    @staticmethod
    def adapt_list_to_dict(data_list: list) -> dict:
        return {f"key_{i}": value for i, value in enumerate(data_list)}

old_system = OldSystem()
new_system = NewSystem()

data = old_system.get_data()
adapted_data = DataAdapter.adapt_list_to_dict(data)
new_system.process_data(adapted_data)
```

## 7. Вывод
Паттерн Адаптер особенно полезен при интеграции legacy-кода с новыми системами, работе со сторонними библиотеками и API, которые могут изменяться независимо от вашего кода. В Python благодаря динамической типизации реализация адаптеров часто проще, чем в статически типизированных языках.
